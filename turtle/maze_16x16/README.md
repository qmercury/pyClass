# 16×16 Turtle 미로 실습

## 준비와 실행

1. 이 폴더의 `maze_starter.py`와 `robot_shape.py`를 **같은 폴더**에 둡니다.
2. Thonny에서 `maze_starter.py`를 열고 실행(F5)합니다.
3. 흰색 16×16 격자와 파란색 로봇, 오른쪽 아래 노란 목표점이 나타납니다.
4. 로봇 모양은 `robot_shape.py`가 Python 코드로 그립니다. 별도의 이미지·패키지는 필요하지 않습니다.

## 좌표 규칙

- 창: 800×800픽셀
- 격자: 16열 × 16행, 총 256칸
- 셀: 40×40픽셀 / `STEP = CELL_SIZE = 40`
- 격자 왼쪽 위 Turtle 픽셀 좌표: `(-320, 320)`
- 시작 셀: `(0, 0)`, 오른쪽 아래 목표 셀: `(15, 15)`
- 좌표는 항상 **(x, y)**, 즉 (열, 행) 순서로 씁니다.
- 로봇은 처음에 시작 셀 **정중앙 `(-300, 300)`**에 위치합니다.
- 셀 `(x, y)`의 왼쪽 위 픽셀 위치:
  - X = `START_X + x * CELL_SIZE`
  - Y = `START_Y - y * CELL_SIZE`
- 셀 중심은 위 식의 X에 20을 더하고, Y에서 20을 빼면 됩니다.
- 격자 기준 상대 픽셀로는 시작 셀 중심이 `(20, 20)`이며, 다음 셀의 중심은 `(60, 20)`입니다.

## 학생 미션

**미션 1 — 벽 한 칸:** `draw_wall(x, y)` 함수를 완성합니다. Turtle로 해당 칸을 검게 그리고, 같은 좌표를 `walls` 집합에 기록하세요.

**미션 2 — 나만의 미로:** 직접 만든 함수를 여러 번 호출하거나 `for` 반복문, `if` 조건문으로 벽을 설계하세요. (0, 0)과 (15, 15)는 막지 않고 두 칸 사이에 통로가 남도록 만듭니다.

**미션 3 — 로봇 이동:** `forward(STEP)`, `robot.left(90)`, `robot.right(90)`을 이용해 40픽셀(한 칸)씩 이동시키세요. 로봇 그림도 방향에 따라 회전합니다.

**미션 4 — 벽 감지 (심화):** 이동할 다음 격자 좌표를 계산하고, `(x, y) in walls`로 벽인지 확인한 뒤 `forward(step)`을 수정하세요. 격자 바깥 이동도 막습니다.

## 수업 시 주의

- **처음 제공하는 `forward(step)`에는 충돌 방지 기능이 없습니다.** 벽을 통과하지 못하게 하는 코드는 학생들의 심화 미션입니다.
- Turtle은 이미 그려진 검은 선이나 사각형을 자동으로 벽이라고 인식하지 않습니다. 그래서 화면에 벽을 그릴 때 벽 위치를 `walls`에 함께 저장해야 합니다.
- `robot.forward(STEP)`는 Turtle의 내장 이동 명령입니다. 실습에서는 `forward(STEP)` 함수를 통해 이동시키며, 나중에 그 함수에 벽 검사를 추가합니다.
- 방향을 90도 단위로 바꾸고 한 번에 40픽셀씩 이동해야 셀 중심에 정렬됩니다.
- `walls`는 실행 중 메모리에만 저장됩니다. 파일 저장 기능은 후속 과제로 다룰 수 있습니다.

## 함수/명령어 힌트

`goto()`, `penup()`, `pendown()`, `forward()`, `right()`, `begin_fill()`, `end_fill()`, `fillcolor()`, `setheading()`, `set.add()`, `in`

학생들이 직접 구현하도록 **벽 그리기와 충돌 판정의 완성 코드는 제공하지 않습니다**.
