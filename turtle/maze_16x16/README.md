# Turtle 16×16 미로 만들기 — 학생용

## 무엇을 제공하나요?

- **기본 제공:** 800×800 Turtle 창, 16×16 빈 격자, 로봇 모양, `STEP = 40` 설정
- **학생이 작성:** 벽 만들기, 벽 좌표 저장, 미로 배치, 로봇 이동 및 벽 충돌 판정

벽을 자동으로 만드는 코드, `draw_wall()` 함수, 충돌 방지 `forward()` 함수는 **들어 있지 않습니다.** 학생이 직접 만들어야 합니다.

## 시작하기

1. 같은 폴더에 `maze_starter.py`와 `robot_shape.py`를 저장합니다.
2. Thonny에서 `maze_starter.py`를 열어 F5로 실행합니다.
3. 빈 격자와 로봇만 나타납니다.
4. `# 여기부터 학생이 직접 작성` 아래에 코드를 작성합니다.

## 좌표 규칙 — 왼쪽 위가 (0, 0)

- 화면 크기: 800×800픽셀
- 좌표 시작점: **화면 왼쪽 위 = (0, 0)**
- X는 오른쪽으로, Y는 아래쪽으로 증가합니다.
- 미로 격자는 화면 왼쪽 위 `(0, 0)`부터 `(640, 640)`까지 차지합니다.
- 격자: 16×16칸, 한 칸 40×40픽셀
- 격자 왼쪽 위 칸 번호는 `(0, 0)`, 오른쪽 아래 칸 번호는 `(15, 15)`입니다.
- 로봇의 시작 위치: **픽셀 (20, 20)** — 첫 칸의 중앙
- 오른쪽 한 칸의 중앙: 픽셀 `(60, 20)`
- 아래쪽 한 칸의 중앙: 픽셀 `(20, 60)`
- 격자 칸 `(x, y)`의 왼쪽 위 픽셀: `(x*40, y*40)`
- 격자 칸 `(x, y)`의 중앙 픽셀: `(x*40+20, y*40+20)`
- `STEP`은 40픽셀이므로 한 칸 거리입니다.

**주의:** 일반 Turtle의 원점은 화면 중앙이고 Y가 위로 증가합니다. 이 템플릿은 `screen.setworldcoordinates(0, 800, 800, 0)`으로 픽셀 좌표계를 적용했습니다. 따라서 화면상 Y가 아래쪽으로 증가하며, `robot.left(90)`과 `robot.right(90)`의 보이는 회전 방향이 일반 Turtle 좌표계와 반대로 나타납니다. 학생들이 방향과 회전 규칙을 관찰하도록 지도하세요.

## 학생 미션 (정답 코드 없음)

1. **한 칸의 벽 만들기:** Turtle로 검은색 사각형 한 칸을 그리는 코드를 작성하세요.
2. **벽 위치 저장하기:** 화면에 그린 벽을 프로그램이 기억하도록 `(x, y)` 좌표를 저장하세요.
3. **미로 만들기:** 반복문과 조건문으로 가로·세로 벽과 통로를 만드세요.
4. **로봇 이동하기:** `robot`과 `STEP`을 이용해 한 칸씩 이동시키세요.
5. **벽 피하기:** 다음 칸에 벽이 있는지 확인하여 이동 여부를 판단하세요. 화면 바깥 이동도 막습니다.

## 참고할 명령어

`goto()`, `penup()`, `pendown()`, `forward()`, `left()`, `right()`, `fillcolor()`, `begin_fill()`, `end_fill()`, `set()`, `add()`, `in`

**참고:** Turtle은 화면에 그린 사각형을 자동으로 벽으로 인식하지 않습니다. 벽 좌표를 별도로 저장하도록 학생들이 설계합니다.
