# Turtle 16×16 미로 만들기 — 학생용

## 무엇을 제공하나요?

- **기본 제공:** 800×800 Turtle 창, 16×16 빈 격자, 로봇 모양, `STEP = 40` 설정
- **학생이 작성:** 벽 만들기, 벽의 좌표 저장, 미로 배치, 로봇 이동과 벽 충돌 판정

벽을 자동으로 만드는 코드, `draw_wall()` 함수, 충돌 방지 `forward()` 함수는 **들어 있지 않습니다.** 학생이 직접 만들어야 합니다.

## 시작하기

1. 같은 폴더에 `maze_starter.py`와 `robot_shape.py`를 저장합니다.
2. Thonny에서 `maze_starter.py`를 열어 F5로 실행합니다.
3. 빈 격자와 로봇만 나타납니다.
4. `# 여기부터 학생이 직접 작성` 아래에 자신의 미로 코드를 작성합니다.

## 기본 좌표

- 창: 800×800픽셀
- 격자: 16×16칸, 한 칸 40×40픽셀
- 왼쪽 위 칸: 격자 좌표 `(0, 0)`
- 오른쪽 아래 칸: `(15, 15)`
- 격자 왼쪽 위 화면 위치: `(-320, 320)`
- 로봇의 시작 위치: 첫 번째 칸의 중앙, Turtle 화면 좌표 `(-300, 300)`
- 격자 좌표는 **(x, y) = (열, 행)** 순서입니다.
- 첫 칸의 중심은 격자 왼쪽 위를 기준으로 `(20, 20)`, 오른쪽 한 칸은 `(60, 20)`입니다.
- `STEP`은 40픽셀이므로 한 칸 거리입니다.

## 학생 미션 (정답 코드 없음)

1. **한 칸의 벽 만들기:** Turtle이 검은색 사각형을 그리게 하세요. 어떤 좌표로 이동해야 할까요?
2. **벽 위치 저장하기:** 화면에 그린 벽을 프로그램도 기억해야 합니다. `(x, y)` 좌표를 어떤 자료형에 저장하면 좋을까요?
3. **미로 만들기:** 반복문과 조건문으로 가로·세로 벽과 통로를 만드세요.
4. **로봇 이동하기:** 로봇이 바라보는 방향으로 한 칸씩 움직이게 하세요. 기본 제공 변수 `robot`과 `STEP`을 활용할 수 있습니다.
5. **벽 피하기:** 다음 칸에 벽이 있는지 확인한 후 이동하게 하세요. 미로 바깥도 이동하지 못해야 합니다.

## 참고할 명령어

`goto()`, `penup()`, `pendown()`, `forward()`, `left()`, `right()`, `fillcolor()`, `begin_fill()`, `end_fill()`, `set()`, `add()`, `in`

**참고:** Turtle은 화면에 그린 그림 자체를 벽으로 인식하지 않습니다. 충돌 판정을 위해 벽 좌표를 별도로 기억하는 방법을 학생이 설계해야 합니다.
